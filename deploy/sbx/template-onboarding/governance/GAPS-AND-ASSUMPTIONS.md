# Gating and provenance for MOCA templates: gaps and assumptions (working record)

> **Preview.** The gating and provenance register is implemented but not yet declared Stable;
> interfaces and limits may change. Known limits: this page.

From sbx-template, started 2026-11-02. A living register for the SWE-bench-at-scale work: what is
missing today for image and template gating and provenance, and the assumptions we are working
under. Each entry has an id so the spec, the code and the validation can cite it.

Sources: the inventory [`INVENTORY-2026-11-02.md`](INVENTORY-2026-11-02.md) (MOCA at sbx-template 22e19036), the
2026-10-31 and 2026-11-01/02 bm1 runs, image-factory's records, and the user's decisions below.
